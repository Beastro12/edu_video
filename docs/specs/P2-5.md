
## Design-check changes (Opus design check accdd, 2026-10-17). Binding; they override anything above.

**Sequencing:** start P2-5 only after P2-8 is merged (both touch `voice_gain`). Rebase the spec's
line numbers on the merged head.

**Kinds to add or reclassify:**
- `manim_<key>_retimed.py` (manim_agent.py:85) is paid: keep it whenever its clip's key is
  referenced.
- Stills of rejected review attempts are paid but unreferenced: they are orphans; `--prune` lists
  them with a cost and keeps them, `--prune-paid` deletes them.
- `*.partial-<pid>-<tid>*` leftovers (utils.py:136) in all three folders: never deleted; listed.
- Manifests: read `manifest.json` plus `manifest.<s>.json` for each `s` in `config.STYLES`. Never a
  `manifest*.json` glob (it matches `manifest.partial-….json`).
- The thumbnail's picture of EVERY style is kept (D29 puts the style in its key).
- Level files: recompute each clip's level path with the same function `voice_gain` uses (after
  P2-8's change), and keep the level file of every kept clip.

**Invariant added:** the referenced set also holds the paths that the current `script.json` would
use, for every style in `config.STYLES`, computed the way `estimate_cost` computes them. A stopped
run leaves bought files and no manifest; those are never orphans.

**Invariant narrowed:** clips count only against the current `manifest.json`; the "referenced by
any manifest" rule applies to paid files and level files.

**Paths:** a manifest path that is absolute or resolves outside `build/<slug>/` is never deleted
(conftest.py:158 writes absolute visual paths). Test it.

**Prune during a run (orchestrator decision):** no lock. Because partials and the current script's
computed paths are always kept, a concurrent run of the same script loses nothing. README's
`--prune` line says not to prune while that film is building.

**Feasibility:** there is no chars-per-second setting; use
`EST_CHARS_PER_WORD × WORDS_PER_MIN / 60` (12 chars/s). Prune runs after the style is resolved
and before `mkdir` / `run_report.recording` in `main`, and writes no run report.

**Added scenarios:** a stopped run (bought stills, no manifest) → `--prune-paid` deletes nothing
it bought; a `.partial-*` file survives both modes; an absolute manifest path survives both modes.
- **From the P2-8 review (S7):** keep `master_level.json` (build root; D32). It is a reading, free
  to remake, but deleting it makes a fresh film read once.
